# 도감 구성 기준

`src/data/objects.json`의 사물-노벨상 연결을 고칠 때 따르는 기준입니다. 1차·2차 구분은 데이터에서 자동으로 계산합니다(`src/lib/collection.ts`의 `computeTiers`, `scripts/check-data.mjs`).

## 기준

1. **직접 들어 있는 것만 잇는다.** 그 물건 안에 그 발견이 실제로 쓰이거나 그 물건이 발견의 대상일 때만 연결합니다. "이 물건이 연결되는 통신망", "요즘 기종에는 없는 부품"처럼 한 단계 건너거나 대부분의 실물에 해당하지 않는 연결은 쓰지 않습니다.
2. **1차(쉬움) = 집이나 길에서 바로 찍을 수 있는 COCO 사물.** 1단계 객체 감지로 인식합니다. 1차 노벨상은 모두 이 사물들만으로 채울 수 있어야 합니다.
3. **2차(어려움) = 일상에서 찾을 수 있지만 조금 찾아다녀야 하는 사물.** 집 안 구석, 약 상자, 지갑, 학교, 거리에서 찾을 수 있는 것만 둡니다. 병원·실험실·박물관·수족관에 가야만 찍을 수 있는 사물은 넣지 않습니다. 2단계 제로샷으로 인식합니다.
4. **찍을 사물이 없는 노벨상은 열람 전용.** 억지로 사물을 붙이지 않고 2차 도감에서 "준비 중"으로 보여 줍니다. 3단계 LLM 인식이 붙으면 아래 후보로 수집할 수 있게 할 수 있습니다.
5. **COCO가 먼저 잡는 사물은 2단계 사물로 쓰지 않는다.** 지금 파이프라인은 1단계가 아무것도 못 찾았을 때만 2단계를 돌리므로, 병에 든 세제처럼 COCO `bottle`로 먼저 잡히는 물건은 2단계에 닿지 못합니다.

|---|---|

## 열람 전용: 54개와 LLM 후보

3단계 LLM이 붙으면 아래처럼 "그 장면"을 찍은 사진을 판단하게 할 수 있습니다. 후보일 뿐 아직 데이터에는 넣지 않았습니다.

| 노벨상 | LLM 후보 사진 |
|---|---|
| 엑스선의 발견, 컴퓨터 단층촬영(CT), MRI, 핵자기공명 | 엑스레이·CT·MRI 사진이나 촬영 기기 |
| ABO 혈액형 | 헌혈 장면, 헌혈증 |
| mRNA 백신, 디프테리아 혈청, 소아마비 | 예방 접종 장면, 백신 바이알 |
| PCR, 초록 형광 단백질, 탄소-14, 극저온 전자현미경, 전자현미경 | 실험실·박물관·수족관 사진 |
| 외계 행성, 우주배경복사, 블랙홀, 가속 팽창 | 밤하늘, 망원경 |

| 기후 모델 | 일기예보 화면 |
| 그 밖 (힉스, 중력파, 양자 얽힘, 크리스퍼 등) | 일상 사물이 마땅치 않아 열람 전용 유지 |
